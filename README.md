# 🎬 COSINE CINEMA

> 좋아하는 영화 한 편을 고르면, 세 가지 AI 모델이 줄거리를 읽고 닮은 영화 다섯 편씩을 골라 드려요.
> 가상 한국영화 500편 · TF-IDF / Word2Vec / Sentence-BERT 텍스트 기반 영화 추천 웹서비스

🔗 **배포 링크** : https://stopwater47.github.io/cosine-cinema/

---

## 📌 프로젝트 소개

영화 500편의 **줄거리(overview) · 장르(genres) · 키워드(keywords)** 를 하나의 텍스트(<code>model_text</code>)로 합친 뒤,
서로 다른 세 가지 방식으로 영화를 벡터로 바꾸고 **코사인 유사도(Cosine Similarity)** 로 가장 닮은 영화 5편을 찾습니다.

같은 영화를 넣어도 모델마다 "닮았다"의 기준이 달라서, 세 모델의 추천 결과를 나란히 놓고 비교할 수 있도록 만들었습니다.
사이트 이름 **COSINE CINEMA** 도 세 모델이 공통으로 사용하는 코사인 유사도에서 따왔습니다.

| 항목 | 내용 |
|---|---|
| 데이터 | 가상 한국영화 500편 (제목 · 줄거리 · 장르 · 키워드 · 개봉일 · 평점 · 상영시간) |
| 분석 대상 | <code>overview + genres + keywords</code> → <code>model_text</code> |
| 추천 모델 | TF-IDF · Word2Vec · Sentence-BERT |
| 추천 방식 | 코사인 유사도 상위 5편 (자기 자신 제외) |
| 계산 환경 | Google Colab (Python) |
| 배포 | GitHub Pages (정적 웹) |

## 🤖 세 가지 추천 모델

| 모델 | 무엇을 비교하나 | 구현 |
|---|---|---|
| **TF-IDF** | 같은 단어가 얼마나 많이 겹치는지 | Kiwi 형태소 분석 + unigram·bigram TF-IDF |
| **Word2Vec** | 단어의 쓰임새(의미)가 얼마나 비슷한지 | Skip-gram 100차원, 문서 = 단어 벡터 평균 |
| **Sentence-BERT** | 줄거리 문장의 의미가 얼마나 비슷한지 | <code>jhgan/ko-sroberta-multitask</code> 문장 임베딩 |

### 📊 모델 평가 (500편 전체, 추천 5편 평균)

| 지표 | TF-IDF | Word2Vec | Sentence-BERT | 무작위 |
|---|---|---|---|---|
| 장르 2개가 모두 같은 영화 비율 | **0.456** | 0.197 | 0.198 | 0.084 |
| 키워드가 1개 이상 겹치는 비율 | **0.728** | 0.632 | 0.633 | 0.522 |
| 줄거리 요소(배경·인물·사건·주제) 일치 개수 (최대 4) | **3.45** | 3.44 | 3.43 | 0.54 |

- TF-IDF는 장르·키워드처럼 **겉으로 드러난 단어**가 같은 영화를 잘 찾습니다.
- Sentence-BERT는 단어가 달라도 **줄거리 의미**가 비슷한 영화를 골라, 장르가 다른 영화도 추천합니다.
- 세 모델의 추천 목록은 서로 35~41%만 겹쳐, 모델마다 다른 관점의 추천을 제공합니다.

## ✨ 주요 기능

1. **영화 검색 + 자동완성** — 제목·장르·키워드·배경으로 검색, 키보드(↑ ↓ Enter)로 선택
2. **모델별 추천 비교** — 한 영화에 대해 세 모델의 Top 5를 유사도 점수와 함께 나란히 표시
3. **세 모델 공통 추천** — 세 모델이 모두 고른 영화를 따로 모아 가장 믿을 만한 추천으로 제시
4. **TOP 10** — 7,500개(500편 × 3모델 × 5편) 추천 목록에 가장 자주 등장한 영화
5. **장르별 둘러보기** — 장르 필터 · 최신순 / 평점순 / 제목순 정렬
6. **모델 평가 대시보드** — 위 평가 지표를 막대 그래프로 비교
7. **자동 생성 포스터** — 제목의 핵심 사물(등대 · 편지 · 우주선 …) 40종과 분위기(겨울 · 비 오는 날 · 달빛 …) 28종을 조합해 500장의 포스터를 코드로 직접 그림
8. **스크롤 연동 극장 배너** — 포스터 500장으로 만든 원통형 벽이 스크롤에 따라 회전
9. **반응형 레이아웃** — 데스크톱 / 모바일 대응

## 🏗 구조

~~~
[ Google Colab ]
  엑셀 데이터 → EDA → 전처리(model_text) → Kiwi 형태소 분석
        │
        ├─ TF-IDF        ─┐
        ├─ Word2Vec      ─┼─ 코사인 유사도 → 영화별 Top 5
        └─ Sentence-BERT ─┘
        │
        ▼  recommendations.json (추천 결과 · 평가 지표)
[ index.html ]  ←  결과를 페이지 안에 내장 (서버 · DB 불필요)
        │
        ▼
[ GitHub Pages ]  ←  정적 배포
~~~

추천 계산은 Colab에서 미리 끝내고 결과만 웹페이지에 담았기 때문에, 별도의 서버 없이 <code>index.html</code> 하나로 바로 실행됩니다.
